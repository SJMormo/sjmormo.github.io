TFTP Server Module for Network Switch Software

Developed an independent TFTP server module for switch software, implementing the server role of the TFTP protocol as defined by RFC-1350. The module facilitated file uploads and downloads to and from switches.

Key Features

  • Supported concurrent processing of up to 3 read requests from clients, even for the same file, enhancing efficiency
  • Implemented command-based controls for enabling/disabling the server, and configuring the UDP port, timeout, and retry count for re-transmissions
  • Supported protocol extensions defined by RFC2348 and RFC7440 to stay up-to-date with industry standards
